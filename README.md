# K.G School Management System

This project is a frontend implementation of a Kindergarten School Management Dashboard.

It includes Student and Admin dashboard interfaces with a dummy login system. 
This is Version 1 (Frontend Only).

## 🚀 Features

- Responsive Homepage
- Student Login (Dummy Authentication)
- Admin Login (Dummy Authentication)
- Student Dashboard UI
- Admin Dashboard UI
- Clean Folder Structure

## 🛠 Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
